# 비동기 프로그래밍 관련 키워드

## 이벤트 루프 기본 개념

### 단일 스레드 이벤트 루프
하나의 스레드에서 여러 비동기 작업을 순차적으로 처리하는 메커니즘입니다. I/O 대기 시간 동안 다른 작업을 실행하여 효율성을 높입니다.

### 코루틴이 협력적으로 실행
코루틴은 서로 양보하며 실행됩니다. 하나의 코루틴이 I/O 대기 상태가 되면 자발적으로 제어권을 다른 코루틴에 넘겨줍니다.

### I/O 대기 중에만 다른 코루틴 실행
I/O 작업(파일 읽기, 네트워크 요청 등)이 완료될 때까지 기다리는 동안, 이벤트 루프는 다른 코루틴을 실행합니다. 이를 통해 CPU를 효율적으로 활용합니다.

### 이벤트 루프가 블로킹되다?
동기 코드가 이벤트 루프를 차단하는 현상입니다. CPU 집약적인 작업이나 동기 I/O 작업이 이벤트 루프를 점유하면 다른 코루틴이 실행되지 않습니다.

## asyncio 모듈

### asyncio
Python의 비동기 프로그래밍을 위한 표준 라이브러리입니다. 이벤트 루프, 코루틴, 태스크 등을 관리합니다.

### AsyncIterator
비동기 이터레이터입니다. `async for` 문과 함께 사용하여 비동기적으로 데이터를 순회할 수 있습니다.

### async for
비동기 이터레이터를 순회하는 문법입니다. 각 항목을 가져오는 동안 다른 코루틴이 실행될 수 있습니다.

## Task 객체

### task가 뭔데 객체로 괴ㅏㄴ리?
Task는 코루틴을 실행하고 관리하는 객체입니다. 코루틴을 Task로 래핑하면 이벤트 루프가 스케줄링하고 상태를 추적할 수 있습니다.

### .done()
Task가 완료되었는지 확인하는 메서드입니다. True를 반환하면 Task가 정상 완료되었거나 취소되었거나 예외가 발생했습니다.

### .cancelled()
Task가 취소되었는지 확인하는 메서드입니다. True를 반환하면 Task가 취소되었습니다.

### .exceoption()
Task에서 발생한 예외를 반환하는 메서드입니다. 정확한 이름은 `.exception()`입니다.

### await task
Task가 완료될 때까지 대기합니다. Task의 결과를 반환하거나 예외를 발생시킵니다.

### task.result()
Task의 결과를 반환하는 메서드입니다. Task가 완료되지 않았으면 예외가 발생합니다.

### task.cancel()
Task를 취소하는 메서드입니다. 취소 요청을 보내지만 즉시 취소되지 않을 수 있습니다.

## 동기-비동기 변환

### sync_to_async
Django의 동기 함수를 비동기 함수로 변환하는 유틸리티입니다. 동기 ORM 쿼리 등을 비동기 컨텍스트에서 사용할 수 있게 해줍니다.

### SynchronousOnlyOperation
Django에서 동기 전용 작업을 비동기 컨텍스트에서 실행하려고 할 때 발생하는 예외입니다.

## 서브프로세스 관리

### create_subprocess -exec
비동기 서브프로세스를 생성하는 함수입니다. 정확한 이름은 `asyncio.create_subprocess_exec()`입니다.

### pid
프로세스 ID입니다. 실행 중인 프로세스를 고유하게 식별하는 번호입니다.

### returncode
프로세스의 종료 코드입니다. 0은 성공, 0이 아니면 오류를 의미합니다.

### wait()
프로세스가 종료될 때까지 대기하는 메서드입니다.

### terminate()
프로세스에 종료 신호(SIGTERM)를 보내는 메서드입니다. 정상 종료를 요청합니다.

### kill()
프로세스에 강제 종료 신호(SIGKILL)를 보내는 메서드입니다. 즉시 종료됩니다.

## 버퍼 관리

### drain()
버퍼에 남아있는 데이터를 모두 전송하도록 하는 메서드입니다. 비동기 I/O에서 버퍼를 비우는 데 사용됩니다.

### 버퍼 플래시
버퍼에 쌓인 데이터를 실제로 전송하는 작업입니다. `drain()` 메서드가 이를 수행합니다.

## 시간 관련

### datetime.now()
현재 로컬 시간을 반환하는 함수입니다. 타임존 정보가 없습니다.

### timezone.now()
Django에서 현재 UTC 시간을 반환하는 함수입니다. 타임존 인식(timezone-aware) datetime 객체를 반환합니다.

### 타임 아웃
작업이 지정된 시간 내에 완료되지 않으면 취소하거나 예외를 발생시키는 메커니즘입니다.

## JavaScript 관련 (참고)

### supplyAsync
Java의 CompletableFuture.supplyAsync()를 의미하는 것으로 보입니다. Python과는 직접적인 관련이 없습니다.

### fetch
JavaScript의 fetch API입니다. HTTP 요청을 비동기적으로 수행합니다.

### thenapply
Java의 CompletableFuture.thenApply()를 의미하는 것으로 보입니다.

### parseJson
JSON 문자열을 파싱하는 함수입니다. JavaScript의 JSON.parse()를 의미하는 것으로 보입니다.
