# 오디오 처리 관련 키워드

## PyAudio 라이브러리

### pyAudia
PyAudio의 오타로 보입니다. 정확한 이름은 PyAudio입니다.

### portcudo19-dev
PortAudio 개발 라이브러리의 오타로 보입니다. 정확한 이름은 portaudio19-dev입니다. PyAudio를 설치하기 위한 시스템 의존성입니다.

### ptyhon-3pytaudio
Python 3용 PyAudio 패키지의 오타로 보입니다. 정확한 이름은 python3-pyaudio입니다.

### pip install pyaudio
PyAudio 라이브러리를 설치하는 pip 명령어입니다. 오디오 입출력을 위한 Python 바인딩을 제공합니다.

## 오디오 포맷 파라미터

### 16000Hz
샘플레이트 16000Hz. 초당 16000개의 샘플을 사용하여 오디오를 디지털화합니다. STT 서비스에서 자주 사용되는 샘플레이트입니다.

### LINEAR16
선형 PCM 16비트 오디오 포맷입니다. 압축되지 않은 오디오 데이터 형식으로, 각 샘플이 16비트로 표현됩니다.

### 샘플레이트
초당 오디오 샘플 수입니다. 값이 높을수록 더 높은 주파수까지 표현할 수 있지만 파일 크기도 커집니다.

### 비트깊이
각 샘플을 표현하는 데 사용되는 비트 수입니다. 16비트는 일반적으로 CD 품질의 오디오에 사용됩니다.

### 채널수
오디오 채널의 개수입니다. 1은 모노(단일 채널), 2는 스테레오(두 채널)를 의미합니다.

### 오디오 코덱
오디오 데이터를 인코딩/디코딩하는 알고리즘입니다. PCM, MP3, AAC 등이 있습니다.

### 컨테이너 형식
오디오 파일의 포맷을 결정하는 컨테이너입니다. WAV, MP4, OGG 등이 있으며, 실제 오디오 데이터와 메타데이터를 포함합니다.

## FFmpeg 옵션

### -i
입력 파일을 지정하는 옵션입니다. `-i input.wav` 형태로 사용합니다.

### -f
출력 포맷을 지정하는 옵션입니다. `-f s16le`는 signed 16-bit little-endian 포맷을 의미합니다.

### -ar
오디오 샘플레이트를 설정하는 옵션입니다. `-ar 16000`은 16000Hz로 설정합니다.

### -ac
오디오 채널 수를 설정하는 옵션입니다. `-ac 1`은 모노(단일 채널)로 설정합니다.

### -acodec
오디오 코덱을 지정하는 옵션입니다. `-acodec pcm_s16le`는 PCM signed 16-bit little-endian 코덱을 사용합니다.

### -i pip 0
입력 옵션의 오타로 보입니다. 정확한 형태는 `-i input.wav` 또는 표준 입력(stdin)을 사용할 경우 `-i pipe:0`입니다. `pipe:0`은 표준 입력을 의미합니다.

### -f s16le
signed 16-bit little-endian 포맷으로 출력합니다. STT 서비스에서 요구하는 일반적인 오디오 포맷입니다.

### -ar 16000
샘플레이트를 16000Hz로 설정합니다.

### -ac 1
모노(단일 채널) 오디오로 변환합니다.

### -acodec pcm -s16le
PCM signed 16-bit little-endian 코덱을 사용합니다. 정확한 형태는 `-acodec pcm_s16le`입니다. 공백 없이 언더스코어로 연결해야 합니다.

### pipe:1
표준 출력(stdout)으로 데이터를 전송합니다. FFmpeg에서 파이프를 통해 데이터를 전달할 때 사용합니다.
