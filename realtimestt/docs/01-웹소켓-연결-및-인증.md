## WebSocket 프로토콜 기초

### HTTP vs WebSocket

HTTP는 요청-응답 모델을 따르는 단방향 통신 프로토콜입니다. 클라이언트가 요청을 보내면 서버가 응답을 반환하고 연결이 종료됩니다. 반면 WebSocket은 양방향 통신을 지원하는 프로토콜로, 한 번 연결을 수립하면 지속적으로 데이터를 주고받을 수 있습니다.

**HTTP의 한계:**

- 클라이언트가 항상 요청을 먼저 보내야 함
- 실시간 데이터 전송에 비효율적
- 서버에서 클라이언트로의 즉각적인 데이터 전송 불가

**WebSocket의 장점:**

- 양방향 실시간 통신
- 낮은 오버헤드 (HTTP 헤더 없음)
- 서버에서 클라이언트로의 푸시 가능

### WebSocket 연결 수립 과정

WebSocket 연결은 HTTP 업그레이드 요청으로 시작됩니다:

```
1. 클라이언트: HTTP Upgrade 요청
   GET /ws/realtime-stt/ HTTP/1.1
   Upgrade: websocket
   Connection: Upgrade
   Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==
   Sec-WebSocket-Version: 13

2. 서버: 101 Switching Protocols 응답
   HTTP/1.1 101 Switching Protocols
   Upgrade: websocket
   Connection: Upgrade
   Sec-WebSocket-Accept: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

연결이 수립되면 양방향으로 데이터를 주고받을 수 있습니다.

## Django Channels 구조

Django Channels는 Django에 비동기 및 WebSocket 지원을 추가하는 확장입니다.

### ASGI (Asynchronous Server Gateway Interface)

Channels는 ASGI를 사용하여 비동기 요청을 처리합니다. ASGI는 WSGI의 비동기 버전으로, WebSocket과 같은 장기 연결을 지원합니다.

**ASGI 애플리케이션 구조:**

```python
async def application(scope, receive, send):
    if scope["type"] == "http":
        # HTTP 요청 처리
    elif scope["type"] == "websocket":
        # WebSocket 연결 처리
```

### Consumer 패턴

Channels는 Consumer 패턴을 사용하여 WebSocket 연결을 처리합니다. Consumer는 WebSocket 이벤트를 처리하는 클래스입니다.

**주요 이벤트:**

- `connect`: 연결 수립 시 호출
- `disconnect`: 연결 종료 시 호출
- `receive`: 메시지 수신 시 호출

## JWT 쿠키 인증 원리

### JWT (JSON Web Token) 구조

JWT는 세 부분으로 구성됩니다:

1. **Header**: 토큰 타입과 알고리즘
2. **Payload**: 사용자 정보 및 클레임
3. **Signature**: 서명 (위조 방지)

**JWT 예시:**

```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VyX2lkIjoxMjN9.signature
```

### 쿠키 기반 인증

HTTP 요청에서는 헤더에 JWT를 포함할 수 있지만, WebSocket은 헤더를 직접 설정하기 어렵습니다. 따라서 쿠키를 통해 JWT를 전달합니다.

**쿠키 전달 과정:**

1. 클라이언트가 WebSocket 연결 시 쿠키 자동 전송
2. 서버가 쿠키에서 JWT 추출
3. JWT 검증 및 사용자 인증
4. 인증된 사용자 정보를 scope에 설정

## 인증 미들웨어 구현

### JWTWebSocketAuthMiddleware

`transcription/middleware/websocket_jwt_auth.py`에 구현된 인증 미들웨어는 다음과 같이 동작합니다:

```python
class JWTWebSocketAuthMiddleware:
    def __init__(self, inner):
        self.inner = inner
        self.jwt_auth = JWTAuthentication()

    async def __call__(self, scope, receive, send):
        if scope["type"] == "websocket":
            # 쿠키 추출
            cookies = self._extract_cookies(scope)

            # JWT 토큰 검증 및 사용자 인증
            user = await self._authenticate_from_cookies(cookies, scope)

            # scope에 사용자 설정
            scope["user"] = user

        return await self.inner(scope, receive, send)
```

### 쿠키 추출

WebSocket scope의 headers에서 쿠키를 추출합니다:

```python
def _extract_cookies(self, scope):
    cookies = {}
    headers = scope.get("headers", [])

    for header_name, header_value in headers:
        if header_name.lower() == b"cookie":
            cookie_header = header_value.decode("utf-8")
            # "name1=value1; name2=value2" 형식 파싱
            for part in cookie_header.split(";"):
                if "=" in part:
                    name, value = part.split("=", 1)
                    cookies[name.strip()] = value.strip()
            break

    return cookies
```

### 토큰 검증 및 사용자 인증

1. **Access 토큰 검증**: access_token 쿠키가 있으면 먼저 검증
2. **Refresh 토큰 갱신**: access 토큰이 없거나 만료된 경우 refresh_token으로 새 access 토큰 발급
3. **사용자 조회**: 검증된 토큰으로 사용자 정보 조회

```python
async def _authenticate_from_cookies(self, cookies, scope):
    # 1. access 토큰 검증 시도
    raw_access = cookies.get("access_token")
    if raw_access:
        try:
            validated_token = await sync_to_async(
                self.jwt_auth.get_validated_token
            )(raw_access)
            if validated_token:
                user = await sync_to_async(self.jwt_auth.get_user)(validated_token)
                return user
        except (InvalidToken, TokenError):
            pass

    # 2. refresh 토큰으로 새 access 토큰 발급
    raw_refresh = cookies.get("refresh_token")
    if raw_refresh:
        new_tokens = await sync_to_async(
            TokenService.issue_access_from_refresh
        )(raw_refresh)
        # 새 access 토큰으로 사용자 인증
        # ...

    return AnonymousUser()
```

### 연결 수립 처리

`connect` 메서드에서 다음을 수행합니다:

1. **연결 수락**: `await self.accept()`로 WebSocket 연결 수립
2. **상태 초기화**: 세션 ID, 사용자, 경로 등 초기화
3. **인증 확인**: scope에서 사용자 정보 확인

```python
async def connect(self):
    scope = self.scope
    client_host = scope.get("client", [None, None])[0] if scope.get("client") else "unknown"

    try:
        await self.accept()

        # 세션 상태 초기화
        self.session_id = None
        self.session = None
        self.user = None
        self.base_path = None
        self.metadata = {}
        self.sequence_number = 0
        self.chunk_count = 0
        self.start_time = timezone.now()

        # STT 처리 관련 상태
        self.audio_queue = None
        self.stt_processing_task = None
        self.input_format = "webm"
        self.language_code = "ko-KR"
        self.interim_results = True

        # 사용자 정보 확인
        user = scope.get("user")
        if user and user.is_authenticated:
            logger.info(f"WebSocket 연결 수립 성공: user_id={user.id}")
        else:
            logger.warning("WebSocket 연결 수립 (인증 없음)")

    except Exception as e:
        logger.error(f"WebSocket 연결 수립 실패: {str(e)}")
        raise
```

### 연결 종료 처리

`disconnect` 메서드에서 다음을 수행합니다:

1. **STT 처리 태스크 종료**: 실행 중인 STT 처리 태스크 취소
2. **오디오 큐 정리**: 종료 신호 전송
3. **메타데이터 저장**: 최종 메타데이터 저장

```python
async def disconnect(self, close_code):
    # STT 처리 태스크 종료
    if self.stt_processing_task and not self.stt_processing_task.done():
        self.stt_processing_task.cancel()
        try:
            await self.stt_processing_task
        except asyncio.CancelledError:
            logger.info("STT 처리 태스크 취소됨")

    # 오디오 큐에 종료 신호 전송
    if self.audio_queue:
        try:
            self.audio_queue.put_nowait(None)
        except Exception:
            pass

    # 최종 메타데이터 저장
    if self.base_path and self.metadata:
        self.metadata["total_chunks"] = self.chunk_count
        self.metadata["end_time"] = timezone.now().isoformat()
        await sync_to_async(RealtimeSTTService.MetadataPipeline.save_json)(
            self.base_path, self.metadata
        )
```

## 실습: WebSocket 연결 테스트

### 1. 간단한 WebSocket 서버 구현

다음은 간단한 WebSocket Echo 서버 예제입니다:

```python
# simple_websocket_server.py
from channels.generic.websocket import AsyncWebsocketConsumer
import json

class EchoConsumer(AsyncWebsocketConsumer):
    async def connect(self):
        await self.accept()
        print("클라이언트 연결됨")

    async def disconnect(self, close_code):
        print(f"클라이언트 연결 종료: {close_code}")

    async def receive(self, text_data=None, bytes_data=None):
        if text_data:
            data = json.loads(text_data)
            # 받은 메시지를 그대로 다시 전송
            await self.send(text_data=json.dumps({
                "type": "echo",
                "message": data.get("message", "")
            }))
        elif bytes_data:
            # 바이너리 데이터도 그대로 다시 전송
            await self.send(bytes_data=bytes_data)
```

### 2. 클라이언트 테스트 코드

JavaScript로 WebSocket 연결을 테스트합니다:

```javascript
// websocket_test.html
const ws = new WebSocket("ws://localhost:8000/ws/realtime-stt/");

ws.onopen = () => {
  console.log("WebSocket 연결 성공");

  // 시작 메시지 전송
  ws.send(
    JSON.stringify({
      type: "start",
      session_id: "test-session-id",
      mimeType: "audio/webm;codecs=opus",
    })
  );
};

ws.onmessage = (event) => {
  if (typeof event.data === "string") {
    const message = JSON.parse(event.data);
    console.log("받은 메시지:", message);
  } else {
    console.log("받은 바이너리 데이터:", event.data);
  }
};

ws.onerror = (error) => {
  console.error("WebSocket 오류:", error);
};

ws.onclose = () => {
  console.log("WebSocket 연결 종료");
};
```

### 3. 인증 테스트

JWT 쿠키를 포함한 WebSocket 연결을 테스트합니다:

```python
# test_websocket_auth.py
import asyncio
import websockets
import json

async def test_websocket_with_auth():
    # JWT 쿠키를 포함한 WebSocket 연결
    uri = "ws://localhost:8000/ws/realtime-stt/"
    headers = {
        "Cookie": "access_token=your_jwt_token_here"
    }

    async with websockets.connect(uri, extra_headers=headers) as websocket:
        # 시작 메시지 전송
        await websocket.send(json.dumps({
            "type": "start",
            "session_id": "test-session-id",
            "mimeType": "audio/webm;codecs=opus"
        }))

        # 응답 수신
        response = await websocket.recv()
        print(f"서버 응답: {response}")

# 실행
asyncio.run(test_websocket_with_auth())
```
