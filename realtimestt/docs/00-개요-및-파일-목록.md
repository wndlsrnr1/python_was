# 실시간 STT 시스템 개요 및 파일 목록

## 학습 목표

이 문서를 통해 다음을 학습할 수 있습니다:

1. 실시간 STT 시스템의 전체 아키텍처와 데이터 흐름을 이해합니다
2. 각 구성 요소의 역할과 책임을 파악합니다
3. WebSocket, gRPC, 오디오 처리 등 핵심 기술을 실습합니다
4. 완전한 실시간 음성 인식 시스템을 구현할 수 있습니다

## 시스템 개요

실시간 STT(Speech-to-Text) 시스템은 사용자가 말하는 음성을 실시간으로 텍스트로 변환하는 시스템입니다. 이 시스템은 다음과 같은 특징을 가집니다:

- **실시간 처리**: 오디오 스트림을 받는 즉시 STT 처리를 수행합니다
- **양방향 통신**: WebSocket을 통한 실시간 데이터 교환
- **스트리밍 변환**: 오디오 형식 변환과 STT 처리를 동시에 수행합니다
- **비동기 처리**: 여러 작업을 동시에 처리하여 성능을 최적화합니다

## 전체 아키텍처 파이프라인

```
┌─────────────┐
│   클라이언트  │
│  (브라우저)   │
└──────┬──────┘
       │ WebSocket 연결
       │ JWT 인증
       ▼
┌─────────────────────┐
│  WebSocket Consumer │
│  (연결 관리)         │
└──────┬──────────────┘
       │ 오디오 청크 수신
       ▼
┌─────────────────────┐
│  AudioPipeline      │
│  (저장 및 관리)      │
└──────┬──────────────┘
       │ 오디오 데이터
       ▼
┌─────────────────────┐
│  AudioAdapter       │
│  (형식 변환)         │
│  WebM → LINEAR16 PCM │
└──────┬──────────────┘
       │ 변환된 오디오
       ▼
┌─────────────────────┐
│  gRPC Client        │
│  (STT 서버 통신)     │
└──────┬──────────────┘
       │ STT 결과
       ▼
┌─────────────────────┐
│  STTPipeline        │
│  (결과 처리)         │
└──────┬──────────────┘
       │ 전사 결과
       ▼
┌─────────────────────┐
│  ResponsePipeline   │
│  (결과 전송)         │
└──────┬──────────────┘
       │ WebSocket 전송
       ▼
┌─────────────┐
│   클라이언트  │
└─────────────┘
```

## 관련 파일 목록

### 1. WebSocket 및 인증 계층

#### `transcription/routing.py`

- **역할**: WebSocket URL 라우팅 정의
- **주요 내용**: `ws/realtime-stt/` 경로에 `RealtimeSTTConsumer` 연결
- **학습 포인트**: Django Channels의 URL 라우팅 방식

#### `transcription/middleware/websocket_jwt_auth.py`

- **역할**: WebSocket 연결 시 JWT 쿠키 기반 인증 처리
- **주요 내용**:
  - `JWTWebSocketAuthMiddleware`: JWT 토큰 검증 및 사용자 인증
  - `JWTAuthMiddlewareStack`: 미들웨어 스택 구성
- **학습 포인트**: 비동기 환경에서의 인증 처리, 토큰 갱신 로직

#### `transcription/consumers/realtime_stt_consumer.py`

- **역할**: WebSocket 연결 관리 및 메시지 처리
- **주요 내용**:
  - `RealtimeSTTConsumer`: WebSocket Consumer 메인 클래스
  - `Private`: 내부 헬퍼 메서드 (세션 ID 추출, 입력 형식 추출)
  - `MessagePipeline`: WebSocket 메시지 처리 (start, end, audio)
  - `AudioPipeline`: 오디오 청크 생성 및 큐 관리
  - `STTPipeline`: STT 스트림 처리
  - `ResponsePipeline`: 응답 전송 (ack, error, transcription)
- **학습 포인트**: 비동기 WebSocket 처리, 파이프라인 패턴

### 2. 서비스 계층

#### `transcription/services/realtime_stt_service.py`

- **역할**: 실시간 STT 비즈니스 로직 처리
- **주요 내용**:
  - `validate_session`: 세션 검증 및 권한 확인
  - `Private`: 내부 헬퍼 메서드 (gRPC 주소 정규화, 오디오 변환)
  - `AudioPipeline`: 오디오 저장 파이프라인
    - `build_path`: 저장 경로 생성
    - `save_chunk`: 오디오 청크 저장
    - `append_chunk`: 오디오 청크 추가
  - `MetadataPipeline`: 메타데이터 관리 파이프라인
    - `save_json`: 메타데이터 JSON 저장
    - `validate`: 메타데이터 검증
  - `STTPipeline`: STT 처리 파이프라인
    - `process_stream`: STT 스트림 처리
- **학습 포인트**: 서비스 레이어 설계, 파이프라인 패턴, 비동기 스트리밍

#### `transcription/services/realtime_stt_config_service.py`

- **역할**: 실시간 STT 설정 관리
- **주요 내용**:
  - `list_all`: 설정 목록 조회
  - `create`: 설정 생성 (API 키 암호화)
  - `update`: 설정 업데이트
  - `delete`: 설정 삭제
  - `activate`: 설정 활성화 (단일 활성 강제)
  - `deactivate`: 설정 비활성화
  - `get_decrypted_api_key`: API 키 복호화
- **학습 포인트**: 설정 관리, 암호화/복호화, 트랜잭션 처리

### 3. gRPC 클라이언트 계층

#### `modules/realtime_stt/daglo/client.py`

- **역할**: Daglo STT 서버와의 gRPC 통신
- **주요 내용**:
  - `DagloRealtimeSTTClient`: gRPC 클라이언트 메인 클래스
    - `connect`: gRPC 서버 연결
    - `stream_recognize`: 양방향 스트리밍 STT 수행
    - `close`: 연결 종료 및 리소스 정리
  - `Private`: 내부 헬퍼 메서드
    - `create_request_messages`: gRPC 요청 메시지 생성
- **학습 포인트**: gRPC 양방향 스트리밍, Protocol Buffer, 비동기 gRPC

#### `modules/realtime_stt/daglo/speech_pb2.py`

- **역할**: Protocol Buffer로 생성된 메시지 클래스
- **학습 포인트**: Protocol Buffer 메시지 구조

#### `modules/realtime_stt/daglo/speech_pb2_grpc.py`

- **역할**: gRPC 서비스 스텁 클래스
- **학습 포인트**: gRPC 서비스 인터페이스

#### `modules/realtime_stt/daglo/speech.proto`

- **역할**: Protocol Buffer 정의 파일
- **학습 포인트**: Protocol Buffer 문법, 메시지 정의

### 4. 오디오 변환 계층

#### `modules/realtime_stt/daglo/audio_adapter.py`

- **역할**: 오디오 형식 변환
- **주요 내용**:
  - `convert_to_linear16`: 단일 오디오를 LINEAR16 PCM으로 변환
  - `StreamingAudioConverter`: 스트리밍 오디오 변환기
    - `write_chunk`: WebM 청크를 stdin에 전송
    - `read_pcm_chunk`: stdout에서 PCM 청크 읽기
    - `flush`: 남은 데이터 처리
    - `close`: 프로세스 종료
  - `convert_stream_to_linear16`: 스트림을 LINEAR16 PCM으로 변환
- **학습 포인트**: ffmpeg를 이용한 오디오 변환, 스트리밍 처리, 비동기 subprocess

### 5. 데이터 모델 및 저장소

#### `transcription/models.py` (RealtimeSTTConfig)

- **역할**: 실시간 STT 설정 데이터 모델
- **주요 필드**:
  - `provider`: STT 제공업체 (DAGLO, NAVER)
  - `title`: 설정 제목
  - `api_key`: 암호화된 API 키
  - `api_url`: API 서버 URL
  - `is_active`: 활성화 여부
- **학습 포인트**: Django 모델, 암호화 필드 관리

#### `transcription/repositories/realtime_stt_config_repository.py`

- **역할**: 실시간 STT 설정 데이터 접근
- **주요 메서드**:
  - `list_all`: 모든 설정 조회
  - `list_by_provider`: 제공업체별 필터링
  - `get_active`: 활성 설정 조회
  - `deactivate_all`: 모든 설정 비활성화
- **학습 포인트**: Repository 패턴, 데이터 접근 추상화

### 6. API 뷰 계층

#### `transcription/views/realtime_stt_view.py`

- **역할**: 실시간 STT WebSocket 연결 정보 제공
- **주요 내용**:
  - `RealtimeSTTConnectionInfoAPIView`: WebSocket 연결 정보 조회
- **학습 포인트**: API 문서화, WebSocket 연결 가이드

#### `transcription/views/realtime_stt_config_view.py`

- **역할**: 실시간 STT 설정 관리 API
- **학습 포인트**: CRUD API 구현

#### `transcription/serializers/realtime_stt_config_serializer.py`

- **역할**: 실시간 STT 설정 직렬화
- **학습 포인트**: DRF Serializer, 데이터 검증
