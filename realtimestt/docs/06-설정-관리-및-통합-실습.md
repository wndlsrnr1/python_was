## 설정 모델 구조

### RealtimeSTTConfig 모델

실시간 STT 설정은 `RealtimeSTTConfig` 모델로 관리됩니다:

```python
class RealtimeSTTConfig(BaseModel):
    """실시간 STT 전용 설정 모델"""

    PROVIDER_DAGLO = "DAGLO"
    PROVIDER_NAVER = "NAVER"

    provider = models.CharField(max_length=20, choices=PROVIDER_CHOICES)
    title = models.CharField(max_length=100, null=True, blank=True)
    api_key = models.CharField(max_length=255)  # 암호화된 키
    api_url = models.URLField(null=True, blank=True)
    is_active = models.BooleanField(default=False)
```

### 필드 설명

- **provider**: STT 제공업체 (DAGLO, NAVER)
- **title**: 설정 제목 (관리용)
- **api_key**: 암호화된 API 키
- **api_url**: API 서버 URL (선택적)
- **is_active**: 활성화 여부 (단일 활성만 허용)

### 데이터베이스 인덱스

성능 최적화를 위한 인덱스:

```python
class Meta:
    indexes = [
        models.Index(fields=["is_active"]),
        models.Index(fields=["provider", "is_active"]),
    ]
```

## API 키 암호화

### 암호화의 필요성

API 키는 민감한 정보이므로 데이터베이스에 저장할 때 암호화해야 합니다:

- **보안**: 평문 저장 시 유출 위험
- **규정 준수**: 개인정보보호법 준수
- **책임 분리**: 암호화 키와 데이터 분리

### 암호화 구현

`shared_kernel.utils.encryption` 모듈을 사용합니다:

```python
from shared_kernel.utils.encryption import encrypt, decrypt

# 암호화
encrypted_key = encrypt(api_key)

# 복호화
decrypted_key = decrypt(encrypted_key)
```

### 설정 생성 시 암호화

설정을 생성할 때 API 키를 암호화하여 저장합니다:

```python
@staticmethod
@transaction.atomic
def create(data: dict[str, Any], user: User) -> RealtimeSTTConfig:
    """실시간 STT 설정 생성"""
    api_key = data.get("api_key", "")
    encrypted_key = encrypt(api_key) if api_key else ""

    config = RealtimeSTTConfigRepository.create(
        provider=data.get("provider"),
        title=data.get("title"),
        api_key=encrypted_key,  # 암호화된 키 저장
        api_url=data.get("api_url"),
        is_active=data.get("is_active", False),
    )

    return config
```

### 설정 사용 시 복호화

STT 처리 시 암호화된 API 키를 복호화합니다:

```python
@staticmethod
def get_decrypted_api_key(config: RealtimeSTTConfig) -> str:
    """복호화된 API 키 반환"""
    if not config.api_key:
        return ""
    decrypted = decrypt(config.api_key)
    return decrypted or ""
```

## 활성 설정 관리

### 단일 활성 원칙

시스템은 한 번에 하나의 활성 설정만 사용합니다:

- **이유**: 설정 충돌 방지, 명확한 동작 보장
- **구현**: 새 설정 활성화 시 기존 활성 설정 자동 비활성화

### 활성화 처리

설정을 활성화할 때 다른 모든 설정을 비활성화합니다:

```python
@staticmethod
@transaction.atomic
def activate(config_id: UUID, user: User) -> RealtimeSTTConfig:
    """실시간 STT 설정 활성화 (단일 활성 강제)"""
    config = RealtimeSTTConfigRepository.get_by_id(config_id)
    if not config:
        raise ServiceError("Realtime STT config not found", status_code=404)

    # 다른 모든 설정 비활성화
    RealtimeSTTConfigRepository.deactivate_all()

    # 현재 설정 활성화
    activated_config = RealtimeSTTConfigRepository.update(
        config,
        is_active=True
    )

    return activated_config
```

### 활성 설정 조회

STT 처리 시 활성 설정을 조회합니다:

```python
@classmethod
def get_active(cls) -> Optional[RealtimeSTTConfig]:
    """활성화된 실시간 STT 설정 조회"""
    return RealtimeSTTConfig.objects.filter(is_active=True).first()
```

## Repository 패턴

### RealtimeSTTConfigRepository

설정 데이터 접근을 추상화합니다:

```python
class RealtimeSTTConfigRepository(BaseRepository[RealtimeSTTConfig]):
    model_class = RealtimeSTTConfig

    @classmethod
    def list_all(cls) -> QuerySet[RealtimeSTTConfig]:
        """모든 실시간 STT 설정 조회"""
        return RealtimeSTTConfig.objects.all().order_by(
            "provider", "-created_at"
        )

    @classmethod
    def list_by_provider(cls, provider: str) -> QuerySet[RealtimeSTTConfig]:
        """제공업체로 필터링된 설정 목록 조회"""
        return RealtimeSTTConfig.objects.filter(
            provider=provider
        ).order_by("-created_at")

    @classmethod
    def get_active(cls) -> Optional[RealtimeSTTConfig]:
        """활성화된 설정 조회"""
        return RealtimeSTTConfig.objects.filter(is_active=True).first()

    @classmethod
    def deactivate_all(cls) -> None:
        """모든 설정 비활성화"""
        RealtimeSTTConfig.objects.filter(is_active=True).update(is_active=False)
```

## 전체 시스템 통합

### 통합 흐름

전체 시스템은 다음과 같이 통합됩니다:

```
1. 클라이언트 → WebSocket 연결
2. 인증 미들웨어 → JWT 검증
3. Consumer → 연결 수립
4. 시작 메시지 → 세션 검증, 경로 생성
5. 오디오 청크 수신 → 저장, 큐 추가
6. STT 처리 태스크 → 설정 조회, API 키 복호화
7. 오디오 변환 → WebM → LINEAR16 PCM
8. gRPC 스트리밍 → STT 서버 통신
9. 결과 수신 → WebSocket 전송
10. 연결 종료 → 리소스 정리
```

### Consumer 통합

Consumer는 모든 파이프라인을 통합합니다:

```python
class RealtimeSTTConsumer(AsyncWebsocketConsumer):

            await self.MessagePipeline(self).handle_text(json.loads(text_data))
        elif bytes_data:
            await self.MessagePipeline(self).handle_audio(bytes_data)

    async def disconnect(self, close_code):
        """연결 종료"""
        # 리소스 정리
```

## 실습: 완전한 실시간 STT 시스템 구현

### 1. 설정 관리 구현

```python
# config_manager.py
from uuid import UUID
from typing import Optional
from shared_kernel.utils.encryption import encrypt, decrypt
from transcription.models import RealtimeSTTConfig
from transcription.repositories import RealtimeSTTConfigRepository

class ConfigManager:
    @staticmethod
    def create_config(
        provider: str,
        title: str,
        api_key: str,
        api_url: Optional[str] = None
    ) -> RealtimeSTTConfig:
        """설정 생성"""
        encrypted_key = encrypt(api_key)

        config = RealtimeSTTConfigRepository.create(
            provider=provider,
            title=title,
            api_key=encrypted_key,
            api_url=api_url,
            is_active=False,
        )

        return config

    @staticmethod
    def activate_config(config_id: UUID) -> RealtimeSTTConfig:
        """설정 활성화"""
        # 다른 모든 설정 비활성화
        RealtimeSTTConfigRepository.deactivate_all()

        # 현재 설정 활성화
        config = RealtimeSTTConfigRepository.get_by_id(config_id)
        if not config:
            raise ValueError("설정을 찾을 수 없습니다")

        activated = RealtimeSTTConfigRepository.update(config, is_active=True)
        return activated

    @staticmethod
    def get_active_config() -> Optional[RealtimeSTTConfig]:
        """활성 설정 조회"""
        return RealtimeSTTConfigRepository.get_active()

    @staticmethod
    def get_api_key(config: RealtimeSTTConfig) -> str:
        """API 키 복호화"""
        if not config.api_key:
            return ""
        return decrypt(config.api_key) or ""
```

### 2. 통합 WebSocket Consumer

```python
# integrated_consumer.py
from channels.generic.websocket import AsyncWebsocketConsumer
import json
import asyncio
from uuid import UUID
from asgiref.sync import sync_to_async
from transcription.services.realtime_stt_service import RealtimeSTTService
from transcription.services.realtime_stt_config_service import RealtimeSTTConfigService
from transcription.repositories import RealtimeSTTConfigRepository

class IntegratedRealtimeSTTConsumer(AsyncWebsocketConsumer):
    async def connect(self):
        """연결 수립"""
        await self.accept()

        # 상태 초기화
        self.session_id = None
        self.user = None
        self.base_path = None
        self.audio_queue = None
        self.stt_task = None

    async def disconnect(self, close_code):
        """연결 종료"""
        # STT 태스크 종료
        if self.stt_task:
            self.stt_task.cancel()
            try:
                await self.stt_task
            except asyncio.CancelledError:
                pass

        # 오디오 큐 정리
        if self.audio_queue:
            try:
                self.audio_queue.put_nowait(None)
            except Exception:
                pass

    async def receive(self, text_data=None, bytes_data=None):
        """메시지 수신"""
        if text_data:
            data = json.loads(text_data)
            if data.get("type") == "start":
                await self.handle_start(data)
        elif bytes_data:
            await self.handle_audio(bytes_data)

    async def handle_start(self, data):
        """시작 메시지 처리"""
        # 세션 검증
        session_id = UUID(data["session_id"])
        self.user = self.scope.get("user")

        self.session = await sync_to_async(
            RealtimeSTTService.validate_session
        )(session_id, self.user)

        self.session_id = session_id

        # 저장 경로 생성
        from django.utils import timezone
        self.base_path = await sync_to_async(
            RealtimeSTTService.AudioPipeline.build_path
        )(session_id, timezone.now())

        # 오디오 큐 및 STT 태스크 시작
        self.audio_queue = asyncio.Queue()
        self.stt_task = asyncio.create_task(self.process_stt())

        await self.send(json.dumps({"type": "ack", "message": "Session started"}))

    async def handle_audio(self, bytes_data):
        """오디오 청크 처리"""
        if not self.base_path:
            return

        # 오디오 저장
        await sync_to_async(
            RealtimeSTTService.AudioPipeline.append_chunk
        )(self.base_path, bytes_data)

        # 큐에 추가
        if self.audio_queue:
            await self.audio_queue.put(bytes_data)

    async def process_stt(self):
        """STT 처리"""
        # 오디오 청크 제너레이터
        async def audio_generator():
            while True:
                chunk = await self.audio_queue.get()
                if chunk is None:
                    break
                yield chunk

        # 설정 조회
        stt_config = await sync_to_async(
            RealtimeSTTConfigRepository.get_active
        )()

        if not stt_config:
            await self.send(json.dumps({
                "type": "error",
                "data": "활성 STT 설정을 찾을 수 없습니다"
            }))
            return

        # API 키 복호화
        api_token = await sync_to_async(
            RealtimeSTTConfigService.get_decrypted_api_key
        )(stt_config)

        # STT 스트림 처리
        try:
            async for result in RealtimeSTTService.STTPipeline.process_stream(
                audio_generator(),
                self.session_id,
                stt_config=stt_config,
                api_token=api_token,
                language_code="ko-KR",
                interim_results=True,
                input_format="webm",
            ):
                # 결과 전송
                message = {
                    "type": "transcription",
                    "data": {
                        "transcript": result.get("transcript", ""),
                        "is_final": result.get("is_final", False),
                        "language_code": result.get("language_code", ""),
                        "total_duration": result.get("total_duration", 0.0),
                    },
                }
                await self.send(json.dumps(message))

        except Exception as e:
            await self.send(json.dumps({
                "type": "error",
                "data": f"STT 처리 실패: {str(e)}"
            }))
```

## 보안 고려사항

### API 키 보안

- **암호화 저장**: 데이터베이스에 평문 저장 금지
- **메모리 관리**: 복호화된 키는 최소한의 시간만 메모리에 보관
- **로깅 제한**: API 키는 로그에 출력하지 않음

### 인증 및 권한

- **JWT 검증**: 모든 WebSocket 연결에 JWT 인증 필수
- **세션 검증**: 사용자가 세션 소유자인지 확인
- **설정 접근 제어**: 관리자만 설정 생성/수정 가능

### 네트워크 보안

- **TLS/SSL**: gRPC 통신은 항상 암호화
- **토큰 전송**: API 토큰은 메타데이터로 안전하게 전송

### 설정 캐싱

활성 설정을 캐싱하여 데이터베이스 조회를 줄입니다:

```python
from django.core.cache import cache

def get_active_config_cached():
    """캐시된 활성 설정 조회"""
    cache_key = "realtime_stt_active_config"
    config = cache.get(cache_key)

    if config is None:
        config = RealtimeSTTConfigRepository.get_active()
        if config:
            cache.set(cache_key, config, timeout=300)  # 5분 캐시

    return config
```

### 연결 풀링

gRPC 연결을 재사용하여 오버헤드를 줄입니다:

```python
class ConnectionPool:
    def __init__(self):
        self.pool = {}

    async def get_client(self, server_address: str):
        """연결 풀에서 클라이언트 가져오기"""
        if server_address not in self.pool:
            client = DagloRealtimeSTTClient()
            await client.connect(server_address, api_token)
            self.pool[server_address] = client

        return self.pool[server_address]
```
