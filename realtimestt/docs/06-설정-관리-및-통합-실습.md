## 설정 모델 구조

### RealtimeSTTConfig 모델

실시간 STT 설정은 `RealtimeSTTConfig` 모델로 관리됩니다:

```python
class RealtimeSTTConfig(BaseModel):
    """실시간 STT 전용 설정 모델"""

    PROVIDER_DAGLO = "DAGLO"
    PROVIDER_NAVER = "NAVER"

    provider = models.CharField(max_length=20, choices=PROVIDER_CHOICES)
    title = models.CharField(max_length=100, null=True, blank=True)
    api_key = models.CharField(max_length=255)  # 암호화된 키
    api_url = models.URLField(null=True, blank=True)
    is_active = models.BooleanField(default=False)
```

### 필드 설명

- **provider**: STT 제공업체 (DAGLO, NAVER)
- **title**: 설정 제목 (관리용)
- **api_key**: 암호화된 API 키
- **api_url**: API 서버 URL (선택적)
- **is_active**: 활성화 여부 (단일 활성만 허용)

## API 키 암호화

### 암호화의 필요성

API 키는 민감한 정보이므로 데이터베이스에 저장할 때 암호화해야 합니다:

- **보안**: 평문 저장 시 유출 위험
- **규정 준수**: 개인정보보호법 준수
- **책임 분리**: 암호화 키와 데이터 분리

### 암호화 구현

`shared_kernel.utils.encryption` 모듈을 사용합니다:

```python
from shared_kernel.utils.encryption import encrypt, decrypt

# 암호화
encrypted_key = encrypt(api_key)

# 복호화
decrypted_key = decrypt(encrypted_key)
```

### 설정 생성 시 암호화

설정을 생성할 때 API 키를 암호화하여 저장합니다:

```python
@staticmethod
@transaction.atomic
def create(data: dict[str, Any], user: User) -> RealtimeSTTConfig:
    """실시간 STT 설정 생성"""
    api_key = data.get("api_key", "")
    encrypted_key = encrypt(api_key) if api_key else ""

    config = RealtimeSTTConfigRepository.create(
        provider=data.get("provider"),
        title=data.get("title"),
        api_key=encrypted_key,  # 암호화된 키 저장
        api_url=data.get("api_url"),
        is_active=data.get("is_active", False),
    )

    return config
```

### 설정 사용 시 복호화

STT 처리 시 암호화된 API 키를 복호화합니다:

```python
@staticmethod
def get_decrypted_api_key(config: RealtimeSTTConfig) -> str:
    """복호화된 API 키 반환"""
    if not config.api_key:
        return ""
    decrypted = decrypt(config.api_key)
    return decrypted or ""
```

## 활성 설정 관리

### 단일 활성 원칙

시스템은 한 번에 하나의 활성 설정만 사용합니다:

- **이유**: 설정 충돌 방지, 명확한 동작 보장
- **구현**: 새 설정 활성화 시 기존 활성 설정 자동 비활성화

### 활성화 처리

설정을 활성화할 때 다른 모든 설정을 비활성화합니다:

```python
@staticmethod
@transaction.atomic
def activate(config_id: UUID, user: User) -> RealtimeSTTConfig:
    """실시간 STT 설정 활성화 (단일 활성 강제)"""
    config = RealtimeSTTConfigRepository.get_by_id(config_id)
    if not config:
        raise ServiceError("Realtime STT config not found", status_code=404)

    # 다른 모든 설정 비활성화
    RealtimeSTTConfigRepository.deactivate_all()

    # 현재 설정 활성화
    activated_config = RealtimeSTTConfigRepository.update(
        config,
        is_active=True
    )

    return activated_config
```

### 활성 설정 조회

STT 처리 시 활성 설정을 조회합니다:

```python
@classmethod
```

```python
class RealtimeSTTConfigRepository(BaseRepository[RealtimeSTTConfig]):

        """활성화된 설정 조회"""

    def deactivate_all(cls) -> None:
        """모든 설정 비활성화"""
        RealtimeSTTConfig.objects.filter(is_active=True).update(is_active=False)
```

## 전체 시스템 통합

### 통합 흐름

전체 시스템은 다음과 같이 통합됩니다:

```
1. 클라이언트 → WebSocket 연결
2. 인증 미들웨어 → JWT 검증
3. Consumer → 연결 수립 (Handler 초기화)
4. 시작 메시지 → 세션 검증, SessionContext 생성
5. 오디오 청크 수신 → 저장, Queue 추가, SessionContext 업데이트
6. STT 처리 태스크 → 설정 조회, API 키 복호화
7. AudioHandler → Queue에서 청크 생성
8. 오디오 변환 → WebM → LINEAR16 PCM
9. gRPC 스트리밍 → STT 서버 통신
10. STTHandler → 결과 처리 및 전송
11. ResponseHandler → WebSocket 전송
12. 연결 종료 → Queue 종료, 리소스 정리
```

### 초기화 순서 다이어그램

```

│  WebSocket 연결      │
└──────────┬──────────┘

           ▼
```

```python
# config_manager.py
from uuid import UUID
from typing import Optional
from shared_kernel.utils.encryption import encrypt, decrypt
from transcription.models import RealtimeSTTConfig
from transcription.repositories import RealtimeSTTConfigRepository

class ConfigManager:
    @staticmethod
    def create_config(
        provider: str,
        title: str,
        api_key: str,
        api_url: Optional[str] = None
    ) -> RealtimeSTTConfig:
        """설정 생성"""

            title=title,
            api_key=encrypted_key,
            api_url=api_url,
            is_active=False,

    @staticmethod

        config = RealtimeSTTConfigRepository.get_by_id(config_id)
        if not config:
            raise ValueError("설정을 찾을 수 없습니다")

        activated = RealtimeSTTConfigRepository.update(config, is_active=True)
        return activated

    @staticmethod
    def get_active_config() -> Optional[RealtimeSTTConfig]:
        """활성 설정 조회"""
        return RealtimeSTTConfigRepository.get_active()

    @staticmethod
    def get_api_key(config: RealtimeSTTConfig) -> str:
        """API 키 복호화"""
        if not config.api_key:
            return ""
        return decrypt(config.api_key) or ""
```

### 2. 통합 WebSocket Consumer (개선된 버전)

```python
# integrated_consumer.py
from channels.generic.websocket import AsyncWebsocketConsumer
import json
import asyncio
from typing import Any
from uuid import UUID
from asgiref.sync import sync_to_async
from django.utils import timezone

from transcription.services.realtime_stt_service import RealtimeSTTService
from transcription.services.realtime_stt_config_service import RealtimeSTTConfigService
from transcription.consumers.realtime_stt_message_handler import MessageHandler
from transcription.consumers.realtime_stt_response_handler import ResponseHandler
from transcription.consumers.realtime_stt_stt_handler import STTHandler
from transcription.consumers.session_context import SessionContext

class IntegratedRealtimeSTTConsumer(AsyncWebsocketConsumer):
    """통합 실시간 STT Consumer (개선된 버전)
    
    - Handler 패턴 사용
    - SessionContext를 통한 상태 관리
    - Queue 재사용 불가능 문제 해결
    """
    
    async def connect(self) -> None:
        """연결 수립"""
        await self.accept()
        
        # Handler 초기화
        self.message_handler = MessageHandler(self)
        self.response_handler = ResponseHandler()
        self.stt_handler = STTHandler()
        
        # SessionContext 초기화
        self.session_context: SessionContext | None = None
        self.stt_processing_task: asyncio.Task[None] | None = None

    async def disconnect(self, close_code: int) -> None:
        """연결 종료"""
        # STT 태스크 종료
        if self.stt_processing_task:
            self.stt_processing_task.cancel()
            try:
                await self.stt_processing_task
            except asyncio.CancelledError:
                pass
        
        # Queue 종료
        await self.message_handler.close_queue()
        
        # 최종 메타데이터 저장
        if self.session_context:
            updated_metadata = self.session_context.metadata.copy()
            updated_metadata["total_chunks"] = self.session_context.chunk_count
            updated_metadata["end_time"] = timezone.now().isoformat()
            updated_metadata["duration_seconds"] = (
                timezone.now() - self.session_context.start_time
            ).total_seconds()
            
            await sync_to_async(RealtimeSTTService.MetadataPipeline.save_json)(
                self.session_context.base_path, updated_metadata
            )

    async def receive(
        self, text_data: str | None = None, bytes_data: bytes | None = None
    ) -> None:
        """메시지 수신"""
        async def send_func(text: str) -> None:
            await self.send(text_data=text)
        
        async def send_error_func(message: str) -> None:
            await self.response_handler.send_error(message, send_func)
        
        async def send_ack_func(message: str) -> None:
            sequence = (
                self.session_context.sequence_number if self.session_context else 0
            )
            await self.response_handler.send_ack(message, sequence, send_func)
        
        if text_data:
            try:
                data = json.loads(text_data)
                result = await self.message_handler.handle_text(
                    data, self.session_context, send_error_func
                )
                if result is not None:
                    self.session_context = result
                    if data.get("type") == "start":
                        await send_ack_func("Session started successfully")
                        # STT 태스크 시작
                        self.stt_processing_task = asyncio.create_task(
                            self.stt_handler.process_stream(
                                self.message_handler.audio_queue,
                                self.session_context.session_id,
                                self.session_context.language_code,
                                self.session_context.interim_results,
                                self.session_context.input_format,
                                send_func,
                                send_error_func,
                                lambda: (
                                    self.session_context.sequence_number
                                    if self.session_context
                                    else 0
                                ),
                            )
                        )
                elif data.get("type") == "end" and self.session_context:
                    await self.message_handler.handle_end(
                        self.session_context, send_ack_func, send_error_func
                    )
                    await self.close()
            except json.JSONDecodeError:
                await send_error_func("Invalid JSON format")
        
        elif bytes_data:
            if self.session_context:
                self.session_context = await self.message_handler.handle_audio(
                    bytes_data,
                    self.session_context,
                    self.message_handler.audio_queue,
                    send_error_func,
                )
            else:
                await send_error_func(
                    "Session not started. Send 'start' message first."
                )
```

### 3. 재시작 시나리오 예제

```python
async def restart_stt_processing(self):
    """STT 처리 재시작 (gRPC 재연결 시)"""
    if not self.session_context:
        return
    
    # 1. 기존 STT 태스크 종료
    if self.stt_processing_task:
        self.stt_processing_task.cancel()
        try:
            await self.stt_processing_task
        except asyncio.CancelledError:
            pass
    
    # 2. 기존 Queue 종료 (None 전송)
    await self.message_handler.close_queue()
    
    # 3. 새 Queue 생성 (재사용 불가능)
    self.message_handler.audio_queue = asyncio.Queue()
    
    # 4. SessionContext에서 정보 추출
    session_id = self.session_context.session_id
    language_code = self.session_context.language_code
    interim_results = self.session_context.interim_results
    input_format = self.session_context.input_format  # ffmpeg 재시작에 필요
    
    # 5. 새 STT 태스크 시작
    async def send_func(text: str) -> None:
        await self.send(text_data=text)
    
    async def send_error_func(message: str) -> None:
        await self.response_handler.send_error(message, send_func)
    
    self.stt_processing_task = asyncio.create_task(
        self.stt_handler.process_stream(
            self.message_handler.audio_queue,  # 새 Queue
            session_id,  # SessionContext에서
            language_code,  # SessionContext에서
            interim_results,  # SessionContext에서
            input_format,  # SessionContext에서 (ffmpeg 재시작에 필요)
            send_func,
            send_error_func,
            lambda: self.session_context.sequence_number,  # SessionContext에서
        )
    )
```

```python
        print(f"오디오 청크 {i+1} 전송 (SessionContext 업데이트)")

    await consumer.disconnect(1000)
```

```python
from django.core.cache import cache

def get_active_config_cached():
    """캐시된 활성 설정 조회"""
    cache_key = "realtime_stt_active_config"
    config = cache.get(cache_key)

    if config is None:
        config = RealtimeSTTConfigRepository.get_active()
        if config:
            cache.set(cache_key, config, timeout=300)  # 5분 캐시

    return config
```

```python
class ConnectionPool:
    def __init__(self):
        self.pool = {}

    async def get_client(self, server_address: str):
        """연결 풀에서 클라이언트 가져오기"""
        if server_address not in self.pool:
            client = DagloRealtimeSTTClient()
            await client.connect(server_address, api_token)
            self.pool[server_address] = client

        return self.pool[server_address]
```
