# FastAPI 아키텍처 데모

## 실행 방법

```bash
uvicorn main:app --reload
```

## 확인 사항

1. **미들웨어**: 응답 헤더에 `X-Process-Time`이 포함되는지 확인
2. **의존성 주입**: 터미널에 "데이터베이스 연결 생성/종료" 메시지가 출력되는지 확인
3. **라우터 매칭**: `/items/42` 경로로 접속하여 경로 파라미터가 전달되는지 확인

## 테스트

```bash
# 기본 엔드포인트
curl http://127.0.0.1:8000/

# 경로 파라미터와 의존성 주입
curl http://127.0.0.1:8000/items/42

# 응답 헤더 확인 (X-Process-Time 포함)
curl -i http://127.0.0.1:8000/items/42
```
